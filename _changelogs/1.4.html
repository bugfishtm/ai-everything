Version 1.4

Description: WordPress, versioning, a DAW you can play and record in, and everything needed to run on a public server.

  • WordPress area: a real WordPress site per project — set up with one click, with its own database, PHP and address; own plugins, themes and blocks from starters, live in the site and exported as installable zips; plugins, themes, updates, PHP log and database export in one tab.
  • Versioning: numbered releases in every area — VERSION file, CHANGELOG.md, git tag, a kept copy of exports/, downloads and restore per release, studio release for the AI.
  • Project lists: cards or a list with details, search, sorting, pinned projects and an archive.
  • DAW: MIDI keyboard input and MIDI output, on-screen keyboard and computer-key playing, recording with count-in and quantize, a new transport bar, track headers, peak-hold meters.
  • Public server: docker-compose.server.yml and .env.server.example (ports 80/443 on IPv4 and IPv6, the Studio under its own domain), a setup code for the first account, container hardening.
  • HTTPS: renewal that fits short-lived certificates, a budget for certificate orders, long host names.
  • Security: programs started for users are resolved with the server's own PATH, files of users reach Studio folders only through the strict extractor, the file tree never follows a link out of a project, hardened WebSocket endpoint, login limits per address, disabled accounts run nothing.
  • License: the source is published under the GNU General Public License v3.0 (images released earlier: MIT). What people make with the Studio stays theirs — starter files are CC0-1.0.
  • Documentation: a website (GitHub Pages) with install, server and HTTPS, guide and configuration.

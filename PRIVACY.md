# Privacy Notice

This repository contains the source code of Everything Studio (ai-everything) and, in the `docs/` folder, the source of its GitHub Pages website.

## The GitHub Pages website

This notice applies to the use of the published website on GitHub Pages, not to downloading, cloning, or viewing this repository on GitHub.

The website is a set of static pages. It sets no cookies, uses no analytics and loads no fonts, scripts or other resources from third parties. No personal information is collected, stored, or otherwise processed by the site owner through the website itself.

However, the website is hosted through GitHub Pages. When visiting the published site, GitHub may process technical and usage data under GitHub's own privacy statement, such as server logs or other website-related data.

For information about GitHub's own data handling, see GitHub's Privacy Statement. The site owner's privacy information and legal notice are at:

- [https://bugfishtm.github.io/privacy.html](https://bugfishtm.github.io/privacy.html)
- [https://bugfishtm.github.io/impressum.html](https://bugfishtm.github.io/impressum.html)

## The software

Everything Studio is self-hosted: it runs on the server of whoever installs it, and the accounts, projects, chats and files of its users are stored there. The project owner of this repository has no access to an installation and receives no data from it. Whoever operates an installation is responsible for the personal data processed on it.

An installation contacts third parties only for what its operator and users set up: the AI providers its users connect with their own accounts, the package sources it downloads software from (npm, wordpress.org, Google's Android SDK repository), and the certificate authority when automatic certificates are switched on.

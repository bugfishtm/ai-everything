# 📦 Releases

This folder contains released versions of the software. Some versions might be missing or unavailable as they have been deemed irrelevant or obsolete for distribution.

Everything Studio is released as a Docker image, not as an archive: [bugfishtm/ai-everything](https://hub.docker.com/r/bugfishtm/ai-everything) on Docker Hub, with one tag per version (`1.4`, `1.3` …) and `latest`. To run a certain version, set that tag as the `image:` in `docker-compose.yml`.
